## Meeting Log
You can find our raw scrum meeting notes on this [Doc](https://docs.google.com/document/d/186sFJ5CEYuIAW5VwEVB9jGG7WRSMWNhgxJHnDDDW--M/edit).
- Week 1: Setup and initial work on Currency, Retirement, Auto Loan, and Rent calculators. Assigned tasks for each member and started implementing interfaces and unit tests.
- Week 2: Continued development of interfaces, unit testing, and functionality for Currency, Auto Loan, and Retirement calculators. Created formatting and color code cheat sheets.
- Week 3: Focused on finishing calculator functionality, debugging, merging pull requests, and starting Mortgage and Interest calculators. Interface improvements and consistency across calculators.
- Week 4: Polished team GUI, completed second calculators per person, ensured consistency in results, and added convenience features like popular currency checkbox and country flags.
- Week 5: Integrated all calculator pages into the main dashboard. Worked on Investment, Real Estate, Retirement, and miscellaneous calculators. Began finalizing About, Authors, and Resources panels.
- Week 6: Continued testing and debugging. Focus on Mortgage, Refinance, and Roth IRA calculators. Fine-tuning interfaces and ensuring all calculations were accurate.
- Week 7: Further unit testing and cross-verification of all calculators. Team collaboration on fixing remaining bugs and ensuring final polish.
- Week 8: Final review, testing, and integration. Prepared all calculators for submission and documentation.
## Git Help
If you are completely new to git or would like a refresher, look at the provided [tutorial](https://youtu.be/8JJ101D3knE?feature=shared) and [cheat sheet](education.github.com/git-cheat-sheet-education.pdf).

Some important best practices
1) Do not commit to the main branch. Once a pipeline is running, this won't be possible anyway. Commit changes to a parallel branch and merge.
2) Review and request reviews for any major merge requests.
3) Use git pull often to receive updates from the repo
